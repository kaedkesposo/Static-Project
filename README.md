# What Drives Academic Growth in Chicago Public Schools?

Kaed Esposo

## Description

This project looks at what is related to academic growth in Chicago public
schools. It starts with two obvious candidates, ISBE school designation and
location in the city, and finds that neither sorts schools well by growth.
School poverty (share of low-income students) does better, so the rest of the
project compares schools within poverty groups to see whether school climate,
chronic absenteeism, or enrollment change still relate to growth. All results
are associations, not causes. Growth is measured for the 2023-24 school year.

The final write-up is `static-viz/final.pdf`. It contains six charts: a
boxplot, a choropleth map, two scatter plots, a heatmap, and a grouped bar
chart.
